# Strata 0.2.10 vs 0.2.11 on the split engine

Strata 0.2.11 (2026-11-05) changed the split engine's prompt-path defaults (`FNX_PF_ROWS` 8192 rows x 4 chunks on NVIDIA, shrinking to fit; `FNX_PF_HCSPLIT=2`) and fused the shared expert into the routed launches (`FNX_SH_FUSE=1`). Built from the PR #5258 branch (0.2.11 plus `patches/0002`), same settings as the tuned 0.2.10 runs (`FNX_ARENA=1 FNX_EXPERT_RAM_GIB=20 FNX_POOL_MIN_RESIDENT=384 FNX_PF_STAGE_ROWS=8`, `--spec 6 --lookup 15 --batch 1`), binary swapped, one run each. On the 16 GB cards the automatic buffer choice falls to 4096 rows x 2 chunks.

Failures: 0 in every run. The short run had 8 empty response bodies (vLLM counted them as 0 output tokens; the server log shows 4–25 generated tokens for them), so the 0.2.11 numbers are not contaminated by failures; the cause of the empty bodies was not investigated.

The per-request prompt overhead is not changed by 0.2.11; see [stage-rows.md](stage-rows.md).
